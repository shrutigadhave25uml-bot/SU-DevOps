## Workflow
1. **Backlog:** identified work that is not yet scheduled.
2. **To Do:** work selected for a future sprint.
3. **In Progress:** work currently being developed.
4. **Testing:** work being checked against acceptance criteria.
5. **Completed:** work that meets the Definition of Done.

This static board is documentation; it is not connected to the application's runtime task state.
