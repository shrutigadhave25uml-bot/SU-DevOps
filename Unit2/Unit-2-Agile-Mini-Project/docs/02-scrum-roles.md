## Working agreements
- Keep backlog items small and understandable.
- Discuss blockers during the Daily Scrum.
- Review acceptance criteria before marking a story Done.
- Demonstrate working software during the Sprint Review.
- Record improvement actions during the Sprint Retrospective.

## Definition of Done (suggested)
- Acceptance criteria are met.
- Code runs in a browser without known blocking errors.
- Changes are checked at desktop and mobile widths.
- README or relevant documentation is updated.
- The change is committed to version control.
