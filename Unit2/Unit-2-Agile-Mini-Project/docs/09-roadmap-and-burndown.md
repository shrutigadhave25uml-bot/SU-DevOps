## Example release roadmap
| Phase | Focus | Expected outcome |
|---|---|---|
| Sprint 1 | Setup and student management | Student records can be created, searched, edited and deleted |
| Sprint 2 | Course, attendance and marks | Core academic records can be maintained |
| Sprint 3 | Dashboard, reports and quality checks | MVP demonstration and documentation |
| Future release | Authentication, roles, database, notifications | Safer multi-user system suitable for further development |
